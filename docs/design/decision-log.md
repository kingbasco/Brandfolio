# Design decisions and skill synthesis

- **Owner decision:** expressive creative studio. Stronger color and distinctive typography replace the previous preview, not merely recolor it.
- **Custom proposal:** cobalt action/identity, lilac/yellow expressive surfaces, Outfit + Manrope + IBM Plex Mono. Superseded by the later TapTap selection.
- **Reference:** Awesome DESIGN.md Figma static study supplies principles of color pacing and specimen-led storytelling, not proprietary assets or live-site claims.
- **Premium:** shared interaction contracts, canonical owners, stable states, non-native product confirmations and token mapping.
- **UI UX Designer:** users/jobs first, spacing scale, semantic tokens, component anatomy/states and handoff coverage.
- **Impeccable:** mode-specific expression, replacement of rejected world, artifact-led composition and bounded visual verification. CLI unavailable; manual context fallback used.
- **DesignSystem:** bundled Impeccable init used to record PRODUCT.md from established requirements, then resumed requested system work. No duplicate product truth file.
- **Redesign:** audit the rejected visual direction as an anti-reference; preserve product goals. No existing repository code to preserve or migrate.
- **Better Design:** team rules were empty; project-local rules are documented here, not saved as account-wide rules. Catalog returned Cobalt/Cerulean/Interior/Stripe/Playful console; none installed because owner chose a custom expressive studio direction. UI/UX/review principles consulted. No generated-system or remote visual-approval receipt claimed.
